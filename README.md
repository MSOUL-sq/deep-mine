# Deep Mine — MVP 0.2

Браузерная 3D-мультиплеерная игра от первого лица про пещеры: добыча, кирки, строительство.
Three.js + Node.js + Socket.IO.

## Запуск
```
npm install
npm start
```
Откройте http://localhost:3000 (в нескольких вкладках или на нескольких устройствах в одной сети: `http://<IP-компьютера>:3000`).
Тесты серверной логики: `npm test`.

## Управление (ПК)
| Клавиша | Действие |
|---|---|
| WASD, мышь, Space | движение, камера, прыжок |
| ЛКМ (держать) | копать |
| B | включить/выключить режим строительства |
| ПКМ | поставить объект (в режиме строительства) |
| 1–3 / колесо мыши | выбор объекта |
| E | открыть/закрыть мастерскую рядом со станком |
| Esc | меню |

## Что реализовано
- **Мир:** процедурная пещера (value-noise, seed 1337), 96×48×96 блоков, чанки по 16, видимые грани + ambient occlusion.
- **Добыча:** 5 ресурсов, прочность, трещины, частицы, звук. Урон считает сервер.
- **Кирки:** каменная / железная / кристальная, отдельные модели, магазин в мастерской, продажа ресурсов.
- **Строительство:** каменный блок, каменный фонарь (светится и освещает), деревянная опора; прозрачный предпросмотр (зелёный/красный); нельзя строить внутри игроков, вне досягаемости, в воздухе, в оболочке мира.
- **Мультиплеер:** уникальные ID, ники над головами, интерполяция позиций, общий мир, синхронизация добычи и построек. Новый игрок получает все изменения мира.
- **Сервер проверяет:** дальность и доступность блока при добыче, частоту ударов, стоимость и место постройки, покупки и продажи, расстояние до мастерской, скачки позиции.

## Структура
```
client/            index.html, css/style.css
  js/              main, world, player, mining, building, inventory, ui, multiplayer,
                   remote-player, pickaxe, workshop, lanterns, audio
server/            server.js (Express+Socket.IO), game.js (логика), world.js, players.js
shared/            worldgen, blocks, building, economy, constants — общие правила клиента и сервера
tests/             game.test.mjs
```

## Протокол Socket.IO
Клиент → сервер: `join {nickname}` (ack: id, spawn, state, changes, players), `move`, `hit {x,y,z}`,
`place {x,y,z,kind}` (ack), `shop {action,id,amount}` (ack), `respawn` (ack).
Сервер → клиент: `playerJoined`, `playerLeft`, `moves` (пачка 20 раз/с), `block`, `damage`, `state`, `teleport`.

## Ограничения MVP
- Сохранения (этап 6) и мобильное управление (этап 7) ещё не сделаны: мир и игроки живут, пока работает сервер.
- Позиции игроков присылает клиент; сервер лишь отсекает нереальные скачки (полноценной серверной физики нет).
- Построенные блоки не возвращают ресурсы при разрушении.
